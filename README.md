# Calculadora-de-Coste-Real-y-Actualizado-de-Inmuebles
la herramienta interactiva SmartProperty Cost Calculator, diseñada para calcular con precisión legal y financiera el coste real, total y actualizado de una operación inmobiliaria en España.

¿Cómo utilizarla?

Descarga el archivo adjunto en tu ordenador.
Haz doble clic sobre él (se abrirá automáticamente en tu navegador web habitual como Chrome, Edge o Safari).

¿Qué te permite auditar esta calculadora?

Impuestos autonómicos exactos: Tarificación de ITP o IVA + AJD según la Comunidad Autónoma, aplicando bonificaciones por comprador joven, familia numerosa, discapacidad o VPO.
Aranceles oficiales regulados: Cálculo automático de las minutas de Notaría (RD 1426/1989) y Registro de la Propiedad (RD 1427/1989).
Costes financieros de hipoteca: Cuota mensual fija e intereses acumulados devengados hasta hoy (sistema francés).
Actualización real por inflación (IPC del INE): Muestra el verdadero esfuerzo económico que supuso la compra al comparar el valor nominal histórico con el poder adquisitivo actual.

Además, en la esquina superior derecha dispones de un botón para Guardar o Imprimir el informe oficial en PDF con todo el desglose listo para archivar.
